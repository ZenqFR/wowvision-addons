## Français

Addons gratuits pour les joueurs aveugles et malvoyants de **World of Warcraft: Forever**, faits pour fonctionner avec l'addon lecteur d'écran [WowVision](https://github.com/wow-vision/WowVision) : suivre le guide de niveau RestedXP, gérer ses sacs, cibler les créatures de ses quêtes et plus, à l'oreille.

**Télécharger, prévisualiser et écouter ce que dit chacun :** https://zenqfr.github.io/wowvision-addons/ (la page choisit seule le français, l'anglais ou l'allemand).

### Installer

1. Installez d'abord [WowVision](https://github.com/wow-vision/WowVision) : tous ces addons passent par lui.
2. Téléchargez les addons voulus (la page, ou le tableau ci-dessus), ou l'archive qui les contient tous.
3. Décompressez dans `World of Warcraft\_forever_\Interface\AddOns`, pour que chaque addon garde son propre dossier, puis tapez `/reload` dans le jeu.

### Bon à savoir

- Chaque addon ne modifie aucun fichier de WowVision : une mise à jour de WowVision ne l'efface jamais.
- Quatre d'entre eux ont été intégrés à WowVision lui-même (pull requests 112, 113, 114 et 121) ; avec un WowVision récent ils se mettent en retrait et ne font rien, et restent utiles avec une version plus ancienne.
- État honnête : plusieurs addons ont été utilisés en jeu avant d'être publiés ; les autres, et les changements les plus récents, ne sont vérifiés que par des tests hors jeu. Le README de chaque addon dit où il en est.
- Le français et l'anglais sont de l'auteur ; l'allemand est une traduction de l'auteur, non vérifiée par un germanophone.
- Publié sous licence MIT (voir [LICENSE](LICENSE) et [NOTICE](NOTICE) ; des copies sont dans chaque archive). Quelques addons reprennent des parties du code de WowVision, qui ne déclare aucune licence ; ces parties restent sous les conditions de ses auteurs.

### Pour celles et ceux qui travaillent sur les addons

- `python tools/build.py` reconstruit les archives dans `docs/downloads/` et le catalogue que lit la page (`docs/js/data.js`) à partir de `tools/catalog.json` et des fichiers `.toc`. Les archives sont reproductibles.
- Chaque addon a des tests hors jeu : `lua tests/run.lua` depuis son dossier. La plupart ont besoin d'un dossier WowVision à côté de l'addon (ou de `WOWVISION_DIR` qui le désigne). Les nombres de tests du catalogue sont ceux du 2026-11-20.
- La page est du HTML, du CSS et du JavaScript simples dans `docs/` (GitHub Pages), sans bibliothèque et sans requête qui sorte de la page.

*Sans lien avec Blizzard Entertainment et non approuvé par elle. World of Warcraft est une marque de Blizzard Entertainment, Inc. Ce dépôt n'utilise aucune illustration de Blizzard.*

### Install

1. Install [WowVision](https://github.com/wow-vision/WowVision) first: all these addons work through it.
2. Download the addons you want (the page, or the table above), or the archive with all of them.
3. Unzip into `World of Warcraft\_forever_\Interface\AddOns`, so that each addon keeps its own folder, then type `/reload` in the game.

### Good to know

- Each addon changes none of WowVision's files, so a WowVision update never removes it.
- Four of them were merged into WowVision itself (pull requests 112, 113, 114 and 121); with a recent WowVision they step aside and do nothing, and stay useful with an older version.
- Honest status: several addons were used in the game before they were published; others, and the newest changes, are checked by offline tests only. Each addon's README says where it stands.
- French and English are the author's own wording; German is a translation by the author and has not been checked by a native speaker.
- Released under the MIT licence (see [LICENSE](LICENSE) and [NOTICE](NOTICE); copies are in every archive). A few addons adapt parts of WowVision's own code, which declares no licence; those parts stay under its authors' terms.

### For people who work on the addons

- `python tools/build.py` rebuilds the archives in `docs/downloads/` and the catalogue the page reads (`docs/js/data.js`) from `tools/catalog.json` and the `.toc` files. The archives are reproducible.
- Each addon has offline tests: `lua tests/run.lua` from its folder. Most need a WowVision folder next to the addon (or `WOWVISION_DIR` pointing to one). Test counts in the catalogue are as of 2026-11-20.
- The page is plain HTML, CSS and JavaScript in `docs/` (GitHub Pages), with no library and no request leaving the page.
