Addons for WoW: Forever

WowVision, forged for Forever

Free addons that let blind and visually impaired players follow the leveling guide, handle their bags, target their quests and more, by ear, with the WowVision screen reader addon. Pick one, preview what it says, download it.

Install in three steps

  1. Get WowVision

    All these addons work through WowVision, the screen reader addon. Install it first.

    WowVision on GitHub

  2. Download

    Take the addons you want below, or the one archive with all of them.

  3. Unzip, then reload

    Unzip into the AddOns folder, so that each addon keeps its own folder, then type /reload in the game:

    World of Warcraft\_forever_\Interface\AddOns

The addons

Each one is free and changes none of WowVision's files, so a WowVision update never removes it.
